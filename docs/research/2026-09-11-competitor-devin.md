# Cognition / Devin — automatic dev-workflow anatomy (2026-09-11)

Lens: mechanism detail only — ticket→plan→execute→validate→PR→review/repair loops, isolation, retries, human gates, cost metering. Builds on (does not repeat) `docs/research/2026-09-07-context-ecosystem-scout.md` (pricing/seat structure, AI Productivity Guarantee), `docs/research/2026-09-07-multi-agent-orchestration-scout.md` (the 2025 "Don't Build Multi-Agents" essay), and PRD §19.2 (2026-08-22 snapshot — now materially stale on pricing and orchestration).

## Devin (Cognition)

**What it is / status (2026-09)**
- Autonomous cloud "AI software engineer": ticket→PR on its own VMs, plus a local agent (Devin CLI / "Devin Local"), a local IDE (Devin Desktop, ex-Windsurf), and an API/MCP surface. Run-rate revenue $73M (Jul 2025, at Windsurf merger) → $492M (May 2026, Series D $1B @ $26B) → ~$900M (Sep 8, 2026, Series E: $2B raised @ $48B). Named customers: NVIDIA, GE Aerospace, Citi, Cognizant, Infosys, Mercedes-Benz, Itaú (17,000 engineers, 11 months: migrations 5–6× faster, 70% of static-analysis vulns auto-remediated, 2× test coverage). Valuation arc: $10.2B (2025-09-08) → $26B (2026-05-27) → $48B (2026-09-08).
- Architecture: two components — the **Brain** (stateless planning/inference service, always in Cognition's cloud, hosted on Azure) and the **Devbox** (session VM). Explicit FAQ: "Devin is a **compound AI system** and does not currently support third-party LLM API keys" — the polar opposite of DevAgent's BYO-provider moat; Cognition instead sells routing intelligence (Fusion/Adaptive) plus its own SWE-model line (SWE-1.5 2025-10, ~950 tok/s on Cerebras; SWE-1.6 2026-04; SWE-1.7 2026-07-08; SWE-2 2026-09-10; SWE-grep fast-context subagent models 2025-10).
- Isolation: every session runs on a dedicated **microVM** (own kernel), not containers — "our own implementation of microVMs took over a year of hypervisor engineering"; full machine state (memory, process tree, filesystem) is snapshot/restored at hypervisor level so sessions survive async gaps (CI waits, review replies) without burning compute. They open-sourced the disk-snapshot tooling (`blockdiff`, 2025-06-23) and expose a `Hypervisors` API in v3.

**Trigger surfaces**
- **Automations** (GA'd out of Schedules, ~May–Aug 2026, Terraform + v3 API): trigger (Slack message/reaction; GitHub issue/issue-comment/PR/PR-review/review-comment/check-run/push; GitLab MR+pipeline; Linear issue/label/status/priority/assigned/moved; Jira events; Pylon; cron/RRULE schedule or run-once; raw webhook with secret + optional payload regex, ≤200KB) + optional edge-detected conditions (RE2) + action: **start session** (event payload auto-appended to prompt; playbook via `@macro`; tags), **message an existing session**, **Triage Devin** (persistent monitor), or email notification. Multiple triggers OR together; public-repo triggers are opt-in per connection (prompt-injection note in docs).
- **Linear/Jira**: assign ticket → uses the integration's **default playbook** (default is `!plan`); playbook labels (`!implement` etc.) synced as ticket labels; @mention in a comment = your comment is the task. Devin's todo list syncs into Linear's native plan UI; session link + PR link post back; enterprise maps Linear teams → Devin orgs. Jira supports service-account connections and per-project triggers.
- **GitHub**: `/devin <instruction>` comments on any issue/PR; CI-failure automations ("Fix CI Failures" template pushes to the same branch); PR-review autofix loop (below). GitLab/Bitbucket/Azure DevOps/GHES integrations for MRs and reviews.
- **API**: `POST /v3/organizations/{org}/sessions` with `prompt`, `devin_mode` (normal/fast/lite/ultra/fusion), `playbook_id`/`child_playbook_id`, `knowledge_ids`, `secret_ids`/`session_secrets`, **`max_acu_limit`** (per-session ACU cap), `platform` (windows or an **outpost pool name**; children inherit parent placement), `resumable` (default true — preserve VM state after stop), `tags`, and **`structured_output_schema` (JSON Schema Draft 7, ≤64KB) + `structured_output_required` (default true: the agent MUST call `provide_structured_output` with `is_final=true` before its turn ends)**. Response carries `status` (new/claimed/running/exit/error/suspended/resuming), `status_detail` (`working | waiting_for_user | waiting_for_approval | finished | inactivity | usage_limit_exceeded | out_of_credits | out_of_quota | org_usage_limit_exceeded | user_usage_limit_exceeded | total_session_limit_exceeded | payment_declined | error`), `acus_consumed`, `pull_requests[]`, `structured_output`. Also `create_as_user_id` impersonation and a `devin_automation` Terraform resource.
- **Plan gate**: Devin 2.0 (2025-04-03) added **Interactive Planning** — sessions start with a research-grounded plan ("relevant files, findings, preliminary plan in seconds") the user can edit before Devin runs; "Planning Mode on by default" since Jul 2025. Ask Devin (Feb 2026: Ask + Plan sub-modes) generates a "high-context prompt" before Agent mode. In automations/async flows this gate is bypassed — which is why they built async verification (below). Session→session context: `@Sessions` mentions and a "Copy Context" button (AI-generated work summary for handing to another agent, Jan 2026).
- **Local→cloud handoff**: Devin CLI `/handoff` packages conversation + branch + `git diff HEAD` (truncated to 100KB) into a cloud session; open-source `devin-handoff` plugin does the same from Claude Code/Codex/Cursor. The CLI also imports configs from Cursor, Windsurf, Claude Code, Copilot, OpenCode, Zed — explicitly competing with the CLI-agent set DevAgent orchestrates.

**Workflow pipeline (stage by stage)**
1. **Trigger → prompt assembly**: event payload + playbook macro + org Knowledge (retrieved by trigger-description relevance; repo-pinned entries always on; enterprise/org scopes; Devin-suggested knowledge from sessions) + AGENTS.md + SKILL.md skills + governing security profile.
2. **Plan**: Interactive Planning web; plan mode in CLI writes persistent `~/.devin/plans/plan-<session>.md` (editable, resumable, hand-offable; `megaplan` keyword forces clarifying questions); todos sync to Linear/Slack plan UIs.
3. **Execute** on a microVM booted from the org's single active **snapshot**, built from declarative **blueprints** (YAML: repos, steps, GitHub-Actions reuse, env vars, secrets, attachments; Devin proposes the blueprint from repo inspection; classic machine setup deprecated 2026-06-30). Enterprise blueprint tiers add drift warnings, build pinning/rollback, scheduled builds.
4. **PR**: focused diffs; **Stacked PRs** when the agent deliberately decomposes one piece of work (2–100 PRs, GitHub.com only; each layer diffed against the layer below; atomic bottom-up stack merge; Devin watches CI for every layer and "resolves conflicts silently" — asks only on substantive decisions; `unstack` on request).
5. **Validate** (below) → **review/repair loop** (below) → human merge.
6. **Async majority**: as of 2026-05-29, "more Devin sessions are triggered asynchronously (events, automations, schedules, other Devins) than interactively"; framing: "unverified changes will quickly become unmanageable" → machine-verifiable proof attached per PR is a necessity, not a feature.

**Isolation & sandbox**
- Cloud: dedicated microVM per session (kernel-level isolation; their blog argues containerized agents are a security threat and cannot survive async gaps). Session boots a fresh copy of the snapshot; session changes don't persist back. Machine-failure hard blocks now offer "Continue in a new session" (Sep 2026).
- **Devin Outposts** (introduced 2026-07-22, on all paid plans): sessions execute on **customer infrastructure** — "an outpost is a named queue of Devin sessions to be served on your own machines." `devin worker start --outpost=<name>`, or a customer orchestrator over the fleet API (Kubernetes-style list-then-watch SSE), or the open-source `devin-outpost-k8s` operator, or partner runtimes (Namespace, Modal, E2B, Daytona, Cloudflare, Brev). Atomic claim endpoint: 409 on lost race, server-assigned `claim_deadline`, expired claims return to queue; "claims are the only coordination primitive… centralization-free scheduling"; advisory ~16 coordinator cap. Brain/inference stays in Cognition's cloud; the session's network policy is published to the orchestrator as `spec.network_policy` and **the customer must enforce it** (docs warn: no firewall rules installed on your machines). This neutralizes DevAgent's "local-first" differentiation at the architecture level.
- Local agent: OS-level `--sandbox` (bubblewrap+socat on Linux; **fails closed** — refuses to start if sandbox can't resolve; unsupported on Windows) with writable paths derived from `Write(...)` scopes, `Read(...)` deny rules that hide paths entirely from sandboxed commands, loopback network proxy with domain allow/deny + `network_mode` limited (GET/HEAD/OPTIONS), per-command sandbox exclusions with most-specific-rule-wins and most-restrictive-wins across user/team sources, enterprise **Required** enforcement.
- **Security Profiles** (GA Aug 2026): org/enterprise default network allowlists (hostname wildcards + CIDR), MCP allowlists, git read-only vs full, GitHub CLI token removal. **Mandatory profiles intersect** with any lower-level choice (can only tighten), mid-session network grants are clamped to the mandatory envelope, and child sessions inherit the parent's resolved chain — "restrictions can't be escaped by delegating work."

**Validation & self-repair loop**
- Devin runs the repo's own tests/CI (success criteria guidance: "tasks with test suites, CI checks, or verifiable outcomes yield the best results"), watches CI post-PR, and auto-fixes failures — Auto-Fix includes failing CI check names in the fix prompt for single-pass resolution (May 2026).
- **Test mode + computer use** ("Verifying Agentic Development at Scale", 2026-05-29): after PR creation Devin offers **Test the app**; (1) env setup (skills under `.agents/skills/`, secrets requested up front and saved), (2) writes a test plan "grounded in source, not assumptions" (ungrounded plans caused hallucinated UI paths) and **sends it to you before executing**, (3) records its desktop run, writing annotations **before each action** ("Devin will lie less about its findings if it annotates its expected behavior right before performing the action" — TDD-style), (4) returns a **chaptered video + labeled screenshots + chronological pass/fail assertion list** with dead time compressed. Repeated flows (login/SSO) are extracted into deterministic **skills**. Test phase is billed at **1/5th normal usage cost**; test runs approved per day more than doubled in ~2 months. Known failure modes: timing-sensitive assertions (toasts) and "cheating" (running JS in the browser to trigger states instead of clicking through the UI).
- **Review/repair loop**: **Devin Review** (2026-01-21) — smart-diff organization, bug catcher (severe/non-severe), CWE-classified security scanner, codebase-aware chat, code changes applied from chat, merge/automerge in-page; auto-review on PR-open/push/draft-ready with repo- and user-level trigger modes; `/devin review` comment trigger; `npx devin-review <pr-url>` CLI (creates an isolated git worktree, diff-only plus read-only local commands for deeper analysis). **Auto-Fix** (2026-02-10): Devin responds to review comments from *any* bot (linters, CI, security scanners) plus lint and CI failures — Cognition's own admission: this "massively increased our internal token spend." Re-review skipped when diff vs base unchanged (Aug 2026); in-progress reviews canceled on new commits (Jun 2026). The 2026-04-22 "Multi-Agents" post quantifies the generator–verifier loop: Devin Review catches **an average of 2 bugs per Devin-authored PR, ~58% severe**, and works *best when the reviewer starts with a completely clean context* (no shared context with the coder), with a communication bridge that filters findings against the original user intent to prevent loop-spirals and out-of-scope fixes.
- **Security Swarm** (2026-07-01): "Agentic MapReduce" — parallel Devins scan repo segments (batch size 1–500 files, default 5; Normal/Deep effort), compose findings into chained attack paths, then a **separate Devin session per finding reproduces the exploit in an isolated sandbox** (configurable "validate severities" threshold). **Interactive mode pauses for human approval of the generated threat model** before scanning. Scan profiles encode threat model / investigation / triage / validation / remediation guidance; Ingest mode imports external scanner findings (SARIF/CSV/PDF) for triage. Self-benchmark on 50 real GHSA advisories: Devin 72% recall @ $90.23/run vs Claude Security 68% @ $131.87, Codex Security 48% @ $118.20, Cursor Security 26% @ $4.60; claims "30% lower cost than the nearest comparable alternative." Remediation templates require "a regression test that fails before the fix and passes afterward" — the same red-check discipline as DevAgent's gates.
- **Retry/criticism mechanics and 2026 counters**: the Jan 2025 Answer.AI study (below) documented dead-end loops burning ACUs (e.g. spending >a day attempting multi-app deploys a platform doesn't support, hallucinating features). 2026 counters are productized: Session Insights flags L/XL sessions "unhealthy", detects "repeated issues… Devin likely got stuck in a retry loop", and regenerates an improved prompt; automations carry per-session ACU limits + invocation limits (min lowered 3→1 ACU, Jun 2026) + queueing with max concurrent runs/queue depth (Aug 2026); enterprise **hard per-session ACU caps** with real-time approach warnings (Apr 2026); per-org and per-user ACU policies with IdP group tiers; **Devin Coach** (Aug 2026) flags inefficient prompts pre-send; sessions sleep (zero usage) after 30 min idle (enterprise-adjustable 5–120 min); no usage while waiting for user, tests, or repo setup; DeepWiki shows per-generation ACU cost; per-automation Consumption tabs. "If you run out of credits, Automations stop running and Devin Review switches to its smart diff viewer" — graceful degradation, not silent failure.
- **Model-level fix**: SWE-2 (2026-09-10; RL from Kimi K3 2.8T params) trains all reasoning-effort levels in one RL run with a **linear per-effort cost penalty** tuned to the local slope of the Pareto frontier. Measured on FrontierCode 1.1 Main: 127 steps → 53 steps (SWE-2 medium) while scoring higher than SWE-1.7 — i.e. the over-exploration/retry problem is being RL-trained away at the model level (FrontierCode 1.1 Main 50.0%, DeepSWE 1.1 73.0%, Terminal-Bench 2.1 92.8%).

**Human gates & approval UX**
- Default: plan-first interactive sessions; approval cards for blueprint/environment changes, secrets, deploys ("Approve deployment" cards in Teams/Slack), network-access requests (approvable from Slack, Jul 2026), test plans; `waiting_for_approval` surfaced in the API as a status detail.
- Approval diffing: approving an automation update shows old→new line diffs of triggers/actions/prompts (Sep 2026); security-profile changes confirm with warnings; plugin installs show capability-based security notices + trust confirmation.
- Bypass: `bypass_approval` on API session creation; auto-approval toggles for workflow scripts; a "pre-approve testing" preference. Org setting controls whether session participants may open PRs as validated collaborators.
- Blueprint proposal cards gate environment changes card-by-card; workflow scripts require approval unless auto-approve is on.

**Cost model / metering mechanics**
- Unit: **ACU** (Agent Compute Unit) for enterprise (order-form rate; enterprise ACUs "adhere more strictly to task planning and end-to-end testing"). Self-serve: plan quota + prepaid **on-demand credits** (same dollar value as legacy ACUs; rollover, auto-reload, shared pool on Teams). Legacy ACU plans retired; legacy Core users migrated to Free. Current plans (2026-04-14): Free / Pro $20 / Max $200 / Teams from $80/mo — full seats $40 (Pro-equivalent quota + Devin Desktop), unlimited free flex seats drawing shared credits. (Pre-2025 the entry price was $500/mo; Devin 2.0, 2025-04-03, dropped it to $20.)
- What accrues: number/complexity of actions (planning, context gathering, execution, browser, code) + VM time and bandwidth ("typically a small fraction"). Exempt: waiting on user, waiting for test suites, setup/cloning. Windows sessions +9%.
- Modes (API enum): normal; **fast** ("~2x faster, 4x more expensive, same intelligence", Feb 2026); **lite** (cheap, small scope); **ultra** (most capable; notifies on lead-model degradation/recovery, Aug 2026); **fusion** (2026-06-29): frontier main agent + cheap **"sidekick" agent running in parallel with its own cached context**; main agent "takes minimal actions… delegates and monitors," makes the significant decisions; dynamic mid-session routing. On their FrontierCode 1.1 Extended benchmark (updated 2026-08-07): Fusion 63.1 @ **$1.35/task** vs Opus 5 (medium) 63.6 @ $3.51, Fable 5 (xhigh) 64.9 @ $10.53, GPT-5.6 Sol (high) 58.7 @ $3.12 — "up to 60% lower cost"; internally "88% of merged PRs driven entirely by the automated Fusion router." Related: "Making Fable Cheaper Than Opus" (2026-07-13). **Adaptive** (CLI router) meters self-serve at fixed token rates ($0.50/1M input, $2.00/1M output, $0.10/1M cache read — promotional through Jul 7, 2026) regardless of routed model.
- Per-surface metering: Devin Review t-shirt pills **XS ≤2.25 / S 2.25–4.5 / M 4.5–9 / L 9–18 / XL >18 ACUs** per PR (all review jobs summed), per-PR auto-review spend caps (soft block; manual reviews still allowed; re-enable per PR), incremental scans of only new commits; Session Insights sizes **XS ≤2 / S ≤5 / M ≤10 / L ≤20 / XL >20 ACUs** (enterprise thresholds ×10), L/XL flagged unhealthy; every session response exposes `acus_consumed`.
- **Outcome-priced billing**: AI Productivity Guarantee (2026-06-04; see prior scout doc): estimator agent scores every completed session into human-equivalent engineering hours; methodology post discloses calibration — 258 ground-truth sessions from 126 users across 8 deployments, held-out log-scale R² ≈ 0.74, correction `h = 2.28 × m^0.923`, lines-of-code alone R² 0.27 (code volume is a weak effort proxy), merged-PR-or-classifier filter drops 1–20% of sessions, deliberately biased to underestimate. Guarantee pays up to **$10M** if delivered value < paid. Still the only outcome-priced mechanism in the competitive set.

**What DevAgent can learn or steal**
- **Structured-output contract as worker protocol**: `structured_output_schema` + `structured_output_required` (mandatory final JSON validated server-side) is DevAgent's sentinel-exit idea (idea #4, 09-07 synthesis) implemented as an API primitive — adopt schema-required worker exits.
- **Deterministic replayable orchestration**: Dynamic Workflows' hash-keyed agent-call recording, replay-on-resume, and "editing a prompt re-runs that agent and everything downstream" is a cleaner formalization of DevAgent's ledger/pick semantics; apply to selfbuild-loop resume.
- **Snapshot economics**: hypervisor snapshot/resume across async gaps + zero-usage waits vs DevAgent's wall-clock timeout burn (issue #306-adjacent: complete on streamed markers, bound in-process retries).
- **Evidence-per-PR is now matched**: chaptered test videos, pass/fail assertion lists, annotate-before-action anti-lying, 1/5-price test mode, Security Swarm's per-finding sandbox repro. What survives as DevAgent's differentiator is backend-domain gate *depth* (migration safety, FK integrity, async/race) — Cognition is one product decision away from analogous domain gates.
- **Clean-context verifier loop** (2 bugs/PR, 58% severe, no shared context + intent-filter bridge) is directly borrowable for DevAgent's review/auditor stage and G-gates.
- **Cost governance UX**: hard per-session caps with approach warnings, unhealthy-session labeling, retry-loop diagnosis + improved-prompt regeneration, pre-send prompt coaching — a menu for DevAgent ledger analytics (FR-GROK-03).
- **Threats**: compound-system no-BYO-keys protects their margin and removes the BYO cost argument via Fusion/Adaptive; Outposts removes "local-first"; stacks + silent conflict resolution + atomic stack merge outclass serial per-branch merge gating; Devin Review's GitHub/GitLab/GHES embedding + Review API + public-PR free tier (devinreview.com) is a distribution play DevAgent cannot match.
- **Notable strategy shift**: "Don't Build Multi-Agents" (2025-06-12, covered in prior scout doc) was formally revised by the same author — "Multi-Agents: What's Actually Working" (2026-04-22): writes stay single-threaded; readonly/sidekick/verifier agents and "map-reduce-and-manage" manager Devins are live in the product (Devin Manages Devins, 2026-03-19; nested sub-Devin session trees, Aug 2026). DevAgent's planner→workers→merger pattern is now the industry-endorsed shape, not a heresy.

## Devin supporting surfaces (2026 naming)

**Parallel Devins / Managed Devins / Dynamic Workflows / Devin Swarm**
- **Managed Devins** ("Devin can now Manage Devins", 2026-03-19): any session can spawn child Devins, each on its own isolated VM, with prompts, playbooks, tags, and **ACU limits per child**; coordinator scopes work, messages children, sleeps/terminates them, schedules self-reminders; children return **structured JSON via schema** (Apr 2026). Sub-Devin sessions render as nested trees; archiving a parent closes children's PRs (Sep 2026).
- **Dynamic Workflows**: Devin writes a **deterministic Python script** that orchestrates agents: primitives `register_workflow(meta)`, `await agent(prompt, phase, schema, label)`, `pipeline(items, ...stages)` (no barrier between stages), `parallel([...])`, `log()`. Every agent call is **recorded against a run ID keyed by hash of prompt+schema+settings**; resume replays completed calls, re-runs only downstream of edited prompts; workflow logic must be side-effect-free (no time/random/env/FS/network reads outside `agent()` calls). Agent runs on its own VM (default; handoffs via git branches + structured output) or shares the orchestrator's working tree (lower concurrency cap, writers must be disjoint). Budget default+max **7 days**. Failed agents: script decides (skip/default/retry/fail); resumed runs retry with fresh sessions. Working workflows are saved as **skills** (`workflow.py` + `SKILL.md` in-repo). This is the closest shipping analog to DevAgent's loop driver — including the deterministic-reducer framing.
- **Auto-Triage** (2026-05-18): persistent parent Devin monitors a Slack channel 24/7, dedupes reports, routes to code owners, spawns focused child sub-Devins per bug; parent + children share a persistent **scratchpad** (triage history, routing table, duplicates) that survives restarts — their version of DevAgent's episodic memory/lessons.
- **Subagents (Devin CLI/Local)**: `subagent_explore` (read-only, cheap default model = SWE-1.6 via router) vs `subagent_general` (inherits parent's possibly-premium model); background subagents auto-deny unapproved tools; interrupt parks them instead of killing; `max-nesting` depth opt-in; admin can disable or pin the subagent model. Their claim: "subagents both improve overall coding performance and reduce cost."

**DeepWiki / knowledge**
- DeepWiki (2025-05-05): free public-repo wikis; private-repo wikis via repo indexing (re-indexed every couple hours); `.devin/wiki.json` config; Wiki v2 uses "stronger reasoning, subagents, and agentic page writers" with per-generation ACU cost shown; effort levels with expected ACU ranges; DeepWiki MCP server; Ask Devin scopes to DeepWiki context. DeepWiki is also the context source fed to the productivity estimator.
- Playbooks: structured prompt templates (Procedure / Specifications / Advice / Forbidden Actions / Required from User), `!macros`, version history, per-playbook analytics (sessions, merged PRs), structured-output schema support (Jun 2026), can pin a Devin mode, promotable to enterprise scope, syncable as Linear labels.
- Skills: in-repo `SKILL.md` (same format as Claude Code's agents/ convention), auto-proposed from testing sessions ("Skill Suggestions" via PR), distributable via governed **plugins** (skills+rules+hooks+MCP bundles, enterprise required/optional/forbidden policies, Jul–Sep 2026).
## Windsurf (Cognition) — post-acquisition

**What it is / status (2026-09)**
- Acquired 2025-07-14 after the collapsed OpenAI deal and Google's licensing/poaching of the CEO and core R&D (CNBC; Cognition blog "One Year of Building Together" recounts the 72-hour deal; the "craziest 72 hours" framing is their own). Deal included "Windsurf's IP, product, trademark and brand" (Cognition/X, 2025-07-14). Cognition kept the IDE alive as the GTM arm ("one of us had been building a cloud agent, the other an IDE") and grew 44 → 350 people.
- **Windsurf is now Devin Desktop** (2026-06-02): an over-the-air rebrand; default surface flipped from editor canvas to the **Agent Command Center** (Kanban of local + cloud agent sessions), full IDE retained and backwards-compatible. Per secondary coverage (digitalapplied.com, 2026-06-05): plans/settings/extensions/keybindings carried over automatically; **Cascade (the Windsurf local agent) end-of-life 2026-07-01** (single source for the exact date; corroborated by Cognition docs making Cascade progressively disabled). Devin Desktop is an open **ACP (Agent Client Protocol, Apache-2.0)** host — Codex, Claude Agent, Gemini CLI, OpenCode, Junie run as first-class in-editor agents.
- **Cascade wind-down mechanics** (from Devin docs): enterprise Cascade setting became a scope choice — everywhere / JetBrains-plugin-only / disabled (2026-07-31); "Legacy Cascade now defaults to disabled for enterprise tiers" (2026-08-07); **Devin Local on by default for enterprise** (2026-08-14). Devin Local is the next-gen agent harness shared with Devin CLI ("significantly more token-efficient… up to 30% fewer tokens than Cascade" per docs; described as a Rust rewrite with subagents in secondary coverage only — single source): subagents, OS sandboxing, fine-grained Deny/Ask/Allow permissions (file reads/writes, exec, HTTP fetches, MCP tools), plan mode + worktree sessions (new/existing worktree, merge-back button — direct parity with DevAgent's per-run worktrees), custom agents as `agents/<name>.md`, skills (Cascade Memories/Workflows migrate to skills via a Migration Wizard). ## Cluster synthesis

- **Shared pattern**: trigger → plan (editable, gated) → isolated per-session machine (microVM/worktree/sandbox) → repo-tests + CI + *self-generated proof artifacts* (videos, assertion lists, sandbox repros) → clean-context reviewer → auto-fix loop → human merge; metering is action-based (ACU/credits) with hard caps, sleep-on-idle, and unhealthy-session diagnosis; the 2026 frontier is *async-majority* operation, where per-PR evidence is treated as mandatory.
- **The 2026 divergence**: Cognition moved model-level cost/quality into the harness (Fusion sidekicks, Adaptive, SWE-2's cost-penalized RL) instead of BYO keys — DevAgent's BYO-provider moat now argues flexibility, not cost; meanwhile Outposts + ACP open-ness attack "local-first" from both ends.
- **Validation depth is converging upward**: video evidence + exploit-sandbox repro + regression-test-required remediation put a generalist within one product decision of DevAgent's backend domain gates; only migration-safety (Squawk/Atlas-style), FK integrity, and async/race review remain unclaimed white space (consistent with 09-07 verification scout).
- **Orchestration is converging on the same formalism**: recorded, hash-keyed, deterministic replay of agent calls (Dynamic Workflows) ≈ DevAgent's ledger-as-reducer (09-07 synthesis theme 5) — the differentiator left is who owns the state when the vendor's product is also the orchestrator.
- **Cost honesty as a feature**: every 2026 Devin surface ships a visible meter (review pills, per-generation wiki cost, automation consumption tabs, test-mode 1/5 pricing) and graceful degradation on empty credits; DevAgent's cost ticks should become surfaces, not just ledger rows.
- **Surprise**: the clean-context generator–verifier result (2 bugs/PR, 58% severe, best with zero shared context) contradicts the intuitive "share full traces" half of the 2025 essay — verifier quality comes from context *separation*, bridged only at the findings-filter step.
