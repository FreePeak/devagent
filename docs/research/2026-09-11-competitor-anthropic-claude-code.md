## 1. Claude Code GitHub Actions (`anthropics/claude-code-action`)

**What it is / status (2026-09)**
`@v1` (beta migrated: `mode` dropped — auto-detected; `direct_prompt`→`prompt`; `custom_instructions`→`claude_args:"--append-system-prompt"`; `max_turns`/`model`/`allowed_tools`/`mcp_config` folded into `claude_args`). A wrapper **built on the Claude Agent SDK** that installs Claude Code + Bun on the runner (`path_to_claude_code_executable`/`path_to_bun_executable` for Nix/custom images). `claude-code-base-action` is the lower primitive: **no actor checks, no base-ref config restore**.

**Trigger surfaces**
Interactive (no `prompt`): `@claude` as a complete word (`trigger_phrase`), in issue/PR comments, PR review comments, new-issue body/title; `assignee_trigger`; `label_trigger`. Automation (`prompt` set): any event — `schedule`, `workflow_dispatch`, `repository_dispatch`, `pull_request`, `workflow_run`. `track_progress` forces tracking comments; `use_sticky_comment` collapses to one.

**Workflow pipeline (stage by stage)**
1. **Actor gate:** write access required on issue/PR events (override `allowed_non_write_users`, RISKY, only with `github_token`); bots rejected unless in `allowed_bots`; on `workflow_run` **both** the workflow actor and the upstream run's actor (fork author) are checked.
2. **Shallow checkout:** `--depth=20` PRs, `--depth=1` new branches.
3. **Base-ref config restore (pwn-request defence):** a fixed path list is restored **from the base branch** — `.claude/`, `.mcp.json`, `.claude.json`, `.gitmodules`, `.ripgreprc`, `CLAUDE.md`, `CLAUDE.local.md`, `.husky/`; absent-on-base paths are removed, PR copies quarantined to `.claude-pr/`. Everything else (lockfiles, `package.json`, `Makefile`, `node_modules/`, lint config) **stays at PR head**, so a base-branch hook invoking `npm run x`/`bunx tool` runs head-controlled code (docs also flag `bunfig.toml` `preload` when `node` is off PATH).
4. **Headless start** with `claude_args`. **Bash disabled by default** — opt in per command: `--allowedTools "Bash(npm:*),Bash(git:*)"`. GitHub MCP + a file-ops MCP server are pre-wired but their tools still need explicit allowlisting (inline-comment posting works only because `claude_args` names `mcp__github_inline_comment__create_inline_comment`).
5. **Work:** Explore→Plan→Implement→Commit into **one** comment with progress checkboxes.
6. **Branch/commit:** `claude/` prefix (`branch_prefix`); open PRs push to the PR branch, closed PRs/issues branch. Unsigned unless `use_commit_signing` (API signing, no rebasing) or `ssh_signing_key` + `bot_id`/`bot_name` (defaults `41898282`/`claude[bot]`).
7. **No auto-PR:** commits + a **pre-filled PR-creation link**; a human clicks.
8. **No merge / no self-approval:** never rebases, force-pushes or merges; cannot submit a formal review (bot identity). The git restrictions live in the **system prompt**, so granting `Bash(git rebase:*)` still gets a decline.
9. **CI visibility:** `additional_permissions: actions: read` grants runs/job logs/test results ⇒ the CI→model path is **pull, model-initiated**, not push.
10. **Comment hygiene:** `classify_inline_comments` (default on) buffers subagent inline comments and classifies real-review vs test/probe **with Haiku** before posting; `include_fix_links` adds "Fix this" deep links that open Claude Code with the finding's context; `include_/exclude_comments_by_actor` (`*[bot]`) filter input.
11. GitHub blocks workflows on `GITHUB_TOKEN` commits, so **passing `github_token` breaks Claude's own CI**; and Claude has no workflow-write permission at all (cannot edit CI config).

**Isolation & sandbox**
GitHub-hosted runner; short-lived App token scoped to the triggering repo. Default auth = workload identity federation exchanging the workflow's OIDC token (`anthropic_federation_rule_id` `fdrl_…`, `anthropic_organization_id`, `anthropic_service_account_id`, `anthropic_workspace_id`, `anthropic_oidc_audience`; needs `id-token: write`) — no static secret. With `allowed_non_write_users` the action adds **subprocess secret scrubbing** (`CLAUDE_CODE_SUBPROCESS_ENV_SCRUB`) and **bubblewrap PID-namespace isolation** on Linux, plus `CLAUDE_CODE_SCRIPT_CAPS='{"edit-issue-labels.sh":2}'` — a per-helper-script call ceiling per run.

**Validation & self-repair loop**
Thin: `--max-turns` bounds iterations; `actions: read` enables self-diagnosis on request. No built-in re-fire on CI failure; practitioners chain `workflow_run` or use the review app's push-triggered mode.

**Human gates & approval UX**
Write-access + human-actor gates, no auto PR, no self-approval, minimum `permissions:`, org secrets, custom App to shrink to Contents/Issues/PRs. Injection posture: input sanitized (HTML comments, invisible chars, image alt text, hidden attributes, entities stripped) with an explicit "new bypass techniques may emerge"; `pull_request_target`/`workflow_run` must not check out an untrusted ref at the workspace root (use a subdir + `--add-dir`). `show_full_output` / `ACTIONS_STEP_DEBUG` dump everything — **publicly visible on public repos**.

**Cost model / metering**
Two meters (Actions minutes + tokens); levers `--max-turns`, `timeout-minutes`, `concurrency`, concise CLAUDE.md, issue templates. `claude_code_oauth_token` (`claude setup-token`) bills to a subscription instead of API — the line §5's episode tried to move.

**Steal for DevAgent**
`CLAUDE_CODE_SCRIPT_CAPS` (per-helper call budget in the pane runner); env-scrub + PID-ns for workers handling externally-authored text (DevAgent's loop ingesting issue bodies *is* the `allowed_non_write_users` threat model); "model-facing config comes from a trusted ref, everything else may be hostile" as a path allowlist replacing the PRD-currency heuristic; Haiku pre-classification of the model's own draft output before it becomes evidence; `actions: read`-style read-only CI window instead of `Bash(gh:*)`.

**Sources**: `docs/en/github-actions`; action repo `docs/{usage,security,faq}.md`.

## 2. Claude Agent SDK — the headless substrate

**Status (2026-09)**
Renamed from Claude Code SDK (post 2025-09-29). Python/TS only, both **bundle a native Claude Code binary**; other languages: "run the CLI as a subprocess with `-p` and `--output-format json`" (DevAgent's path is sanctioned). Docs now say **`--bare` is recommended for scripted/SDK calls and will become the `-p` default** (skips discovery of hooks, skills, commands, subagents, plugins, MCP, auto memory, CLAUDE.md). Managed Agents is a separate hosted product.

**Loop contract (what an orchestrator parses)**
1. `SystemMessage` `init` — model, tools, MCP servers, plugins, `capabilities[]` for feature detection instead of version-string compare.
2. Per turn: `AssistantMessage` (one per content block) then `UserMessage` tool results; **a turn = one round trip**; loop ends on a response with no tool calls. Read-only tools may run concurrently; `Edit`/`Write`/`Bash` are sequential unless a custom tool sets `readOnlyHint`.
3. `ResultMessage.subtype` ∈ `success` | **`error_max_turns`** | **`error_max_budget_usd`** | `error_max_structured_output_retries`. Iterate to stream end (trailing events arrive after the result); single-shot `query()` **throws after** yielding an error result — catch, then `resume`.
4. Other subtypes: `compact_boundary`, `informational`, `worker_shutting_down`.
5. **`system/api_retry`** events: `attempt`, `max_retries`, `retry_delay_ms`, `error_status`, `error` ∈ `rate_limit|overloaded|authentication_failed|billing_error|invalid_request|model_not_found|server_error|max_output_tokens|cloud_credential_error|unknown`, plus `no_response{waited_ms,retry_wait_ms}` — machine-readable provider degradation.

**Budgets / caps**
`max_turns` counts **tool-use turns only** (`max_turns=2` stops before the edit step); `max_budget_usd`/`maxBudgetUsd` **includes subagent spend** — at the cap, spawning another subagent fails with `Budget limit reached` and running background subagents stop. No limits by default.

**Validation & self-repair**
Resume-to-recover is documented first-class ("Recover from a limit … resume with a higher limit"). Hooks gate deterministically (prior file). Structured output: `output_format:{type:"json_schema"}` → validated `structured_output`, **auto re-prompting on mismatch**, bounded retries; CLI `--json-schema` (invalid schema ⇒ exit + validator diagnostic; `format` is annotation-only). Sessions: `resume`/`continue`/fork (branches **conversation**, not filesystem; `--fork-session` on the CLI); transcripts `~/.claude/projects/<encoded-cwd>/*.jsonl`; `persistSession:false` / `CLAUDE_CODE_SKIP_PROMPT_HISTORY` for stateless; **`SessionStore` mirrors transcripts to S3/Redis so other hosts resume**. Process semantics: **SIGTERM ⇒ exit 143**, turn recorded unfinished, Bash tree killed, only `SessionEnd` hooks run, and **resume continues that turn**; SIGINT/`interrupt()` ends a turn cleanly. `-p` kills background Bash ~5 s after the result; background subagents/workflows are awaited, capped at 10 min continuous idle (`CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS`).

**Human gates**
Modes: `default` (unmatched → `canUseTool`; **no callback ⇒ deny**), `acceptEdits`, `plan`, `dontAsk` (deny all not in `permissions.allow`; `AskUserQuestion` and `requiresUserInteraction` MCP tools denied even when allowed), `auto` (classifier), `bypassPermissions`. The unattended flag: **`--permission-prompts none`** — never consults the host, denies what would prompt, **tells the model nobody can approve and not to retry**, keeps `PermissionRequest` hooks as the only escape, strips human-answer tools and cancels unanswered elicitation; under `stream-json` each denial is a `permission_denied` event and the result carries `permission_denials[]`.

**Cost metering**
`total_cost_usd` = that `query()` call **including subagents**; `usage` = main loop only (**undercounts with nesting** — use `modelUsage`/`model_usage` for whole-tree); `output_tokens` on assistant messages is a `message_start` placeholder. Explicit: **client-side estimates from a build-time price table** (override via `modelPricing`; `inference_geo:"us"` ⇒ ×1.1) — **do not bill end users or make financial decisions from them**. In streaming-input mode, `total_cost_usd`/`modelUsage` are running totals since the last `/clear`-family reset and **`maxBudgetUsd` compares against that same total, so `/clear` resets the budget**. `effort` (`low…max`) is a per-session and per-`AgentDefinition` cost lever.

**Steal for DevAgent**
Branch re-dispatch on `result.subtype`; default worker posture `dontAsk` + allowlist + `--permission-prompts none` (kills the "parked on an unanswered approval" failure class and yields a listable denial record); SIGINT before SIGTERM in the watchdog; `system/api_retry` feeding the provider-degraded breaker (memory lesson: `provider_request_failed` came back as HTTP 200 and matched no retryable class).

**Sources**: `docs/en/agent-sdk/{overview,agent-loop,sessions,cost-tracking,structured-outputs}`, `docs/en/headless`.

## 3. Web / mobile / background sessions + routines

**Status**
Claude Code on the web: **research preview** (Pro/Max/Team; Enterprise premium or Chat+Code seats), Anthropic VMs or your **self-hosted environment** (`ccpool_…` pools, public beta Team/Enterprise; ZDR orgs excluded). **Routines** = saved prompt + repos + connectors + triggers (research preview).

**Trigger surfaces**
Web; mobile; `claude --cloud "<task>"` (new cloud session; `--remote` deprecated); `claude -p "msg" --cloud <session-id>` = **queue a follow-up into a running session from any logged-in machine incl. CI, then exit** (`{ok, session_id, url}` under `--output-format json`); `--teleport`/`/tp`/`/tasks`→`t` (pull session+branch into the terminal; **one-way**); background sessions (the `--bg` flag exists; `-p` rejects it) carrying `/loop` tasks across backgrounding; Desktop scheduled tasks; `/schedule` (alias `/routines`); routine `/fire`; GitHub event triggers; `/autofix-pr`; Slack; `claude-cli://` deep links.

**Pipeline**
1. **Cloud environment** governs: network level (**Trusted** = default allowlist), env vars, setup script, **cached environment** (invalidated by config change or `cache:false`), installed tools.
2. **Repo materialisation:** GitHub App, or `/web-setup` (syncs the local `gh` token); **either way a cloud session reaches every repo the connected GitHub account can see** — the App install enables PR webhooks, it is *not* a session ACL. Or **bundle upload** when GitHub isn't connected: full history + uncommitted tracked changes, credential-named files excluded (`.env`, `*.tfvars`, `id_rsa`, `*.pem`), >100 MB ⇒ current branch ⇒ squashed snapshot, untracked never, `CCR_FORCE_BUNDLE=1` to force, and no push without GitHub auth.
3. **Instrumented boot:** live setup checklist; **messages typed during provisioning are queued**.
4. **Work:** `.claude/agents/` subagents auto-load; teams off unless `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`; **the product sets `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` itself and that wins over your env value**, so compaction triggers early.
5. **Review→PR:** `+N −M` indicator → diff → **line comments sent back to Claude**; PR from the session UI; diffs computed from raw git blobs (repo `textconv` drivers don't apply).
6. **Handoff:** `/teleport` requires clean tree, correct repo (refuses forks; error names both), pushed branch, same account; the terminal then owns a **copy** — branch shared, transcript not.
7. **Ultrareview** (`/code-review ultra`): reviewer fleet **in a remote sandbox**, **every finding independently reproduced and verified**; branch mode bundles/uploads, **PR mode uploads nothing** (sandbox clones the PR; connected account must be able to read the repo, checked pre-launch on ≥2.1.248); caps **500 files / 8,000 lines**, whole-repo fallback when no merge base; **3 one-time free runs (Pro/Max), then ~$5–25/review billed as usage credits, and the launch is blocked if usage credits are off**; `claude ultrareview` blocks and prints findings to stdout (`--json` raw `bugs.json`, `--timeout` 45 min, exit **0/1/130**, remote review survives Ctrl-C); `--post` posts one plain comment **as you**, "isn't a review or an approval".

**Isolation**
Isolated Anthropic VM; env allowlist enforced by a proxy (non-allowed hosts fail `403` with `x-deny-reason: host_not_allowed`; connector traffic goes through Anthropic's servers), and **a separate proxy holds the GitHub token outside the sandbox, issuing scoped repo credentials inside it**. Self-hosted routing moves isolation/egress/git-credential duty to you. Control-plane facts: dispatching with `--environment`/`--cloud` needs a **claude.ai OAuth login (API keys rejected)**; the `user:sessions:claude_code` grant is **capped at 30 days**, so `claude setup-token` (one-year, inference-only) doesn't cover it and the runner's env secret only registers runners; pools are created/deleted via `POST/DELETE /v1/code/runners/self-hosted/pools` with `anthropic-beta: ccr-byoc-2025-07-29`, returning a long-lived `pool_secret`; the runner **snapshots `~/.claude/` once at startup**, so hooks need a restart.

**Validation & self-repair**
**Auto-fix pull requests** = the productised loop: on **CI failure** or **new review comment**, triage — *clear fix* ⇒ push + explain; *ambiguous/architectural* ⇒ ask; *duplicate/no-action* ⇒ note. Enable: CI-bar toggle, `/autofix-pr` (detects PR via `gh`, spawns a web session), mobile natural language, or a PR URL. Managed review "after every push" **auto-resolves threads when the flagged issue is fixed**. Session-local: **`/loop`** (fixed cron or self-paced 1 min–1 h; built-in maintenance prompt or `.claude/loop.md` ≤25 KB that "tends the current branch's PR: review comments, failed CI runs, merge conflicts", irreversible pushes only continuing what the transcript authorized; `CronCreate/CronList/CronDelete`, ≤50 tasks, jitter, 7-day expiry, no catch-up), the **`Monitor`** tool (background script, output lines streamed back as notifications — replaces polling), and **Channels** (MCP plugins pushing CI/chat/webhooks into a *live* session: `claude --channels plugin:x@marketplace`, pairing-code + sender allowlist, `.mcp.json` membership explicitly insufficient, permission-relay to your phone).

**Human gates**
Web/mobile mode dropdown; **prompts surface in claude.ai/mobile**; an idle session with a pending question can be answered later, up to environment expiry. **Routines have no picker and no prompts** — bounded by repos + environment + connectors (all included connector tools usable **without asking**; local `claude mcp add` servers aren't connectors). Pushes to `claude/` branches are "always accepted"; a push to any other branch is rejected if it is **protected**, has **someone else's open PR**, or **carries commits authored by someone else**. Owner can disable routines org-wide (server-side; hides `/schedule` ≥2.1.227). Provenance rule: the fired run gets the **saved prompt as an assigned task** (attested as stored ahead of time by an authorized session) while external payload arrives wrapped in **`<routine-fire-payload>`** labelled untrusted and the routine prompt must **opt in** to act on it; before v2.1.213 the saved prompt was framed as untrusted and "could refuse to act on it".

**Cost / limits**
Individual subscription; artifacts attributed to you. Routines: daily cap on runs per account (one-offs exempt), **hourly caps on GitHub webhook events with excess dropped**, min interval **1 h** (Desktop/`/loop`: 1 min); at the cap, usage-credit orgs continue metered, others are **rejected until reset**. `--cloud`/`/schedule` need a claude.ai login and are unavailable on Bedrock/Vertex/Foundry (a gateway via `ANTHROPIC_BASE_URL` alone doesn't count as third-party, but login is still required), gated by `allow_remote_sessions`, which is checked **before** sending and refuses when unfetchable. **A green run status means only "started and exited without an infrastructure error"**; `/schedule why did my nightly review do nothing this morning?` reads run logs incl. tool errors and permission denials (≥2.1.227).

**Steal**
`<routine-fire-payload>`-style provenance labelling for issue-body→prompt; the three branch-rejection rules as a PR-step gate; create- **and** fire-time capability checks failing closed; `Monitor` instead of byte-growth watching; the ultrareview exit-code contract; token-held-outside-the-sandbox split for per-worktree git credentials.

**Sources**: `docs/en/{claude-code-on-the-web,routines,scheduled-tasks,ultrareview,channels,cloud-environments,sandbox-environments,self-hosted-environments-testing}`.

## 4. Native automation primitives

**Checkpoints.** A checkpoint per user prompt; **only the 100 most recent keep file snapshots**, swept ~30 days after last save (`cleanupPeriodDays`). `/rewind` (double-`Esc`) → Restore code and conversation / Restore conversation / Restore code / **Summarize from here / Summarize up to here**; after a conversation restore the original prompt reloads into the input; after `/clear` the menu offers `/resume <session-id> (previous session)` (≥2.1.191). Limits: **Bash-made changes (`rm`/`mv`/`cp`) aren't tracked; subagent edits aren't restored** (except a foreground `context: fork` skill); symlinks/hard-links are skipped with a warning; "not a replacement for version control".

**Sandbox stack (three separable layers).**
1. *Bash sandbox* (built-in; macOS/Linux/WSL2): **bubblewrap** filesystem isolation + `socat`-relayed **proxy domain allowlist** + optional seccomp socket filter. `autoAllowBashIfSandboxed` runs sandboxed commands without prompting (deny rules, critical-path `rm`, content-scoped `ask` still apply); **violations are reported naming the denied path/host** and the `dangerouslyDisableSandbox` hatch re-runs unsandboxed through the normal flow (`allowUnsandboxedCommands:false` = strict). Default is **fail-open** on missing deps; `sandbox.failIfUnavailable:true` makes it a gate; `filesystem.disabled:true` (network-only) is honoured **only from user/managed settings and `--settings` — project settings cannot switch it off**.
2. *`srt` (`@anthropic-ai/sandbox-runtime`)* — wraps the **whole process**, so file tools, hooks and MCP servers are inside the boundary: `npx @anthropic-ai/sandbox-runtime claude`, config `~/.srt-settings.json` or `--settings` (**refuses to start if `--settings` fails to load; with no valid settings it starts anyway, network-denied — "don't take a clean start as proof your settings loaded"**). Read = deny-then-allow (`allowRead` wins); write/network = allow-only (`denyWrite` wins). **Hard project-root denies: `.git/hooks`, `.git/config` (unless `allowGitConfig`), `.mcp.json`, `.claude/commands`, `.claude/agents`, shell startup files** — the persistence paths a compromised session would use. macOS re-checks denies at write time; **Linux builds the deny list once at launch** (`mandatoryDenySearchDepth`; misses mid-session `git init`/clone) and applies write grants only to pre-existing paths. Network goes through host HTTP+SOCKS5 proxies (Linux drops the namespace entirely; macOS allows one localhost port; **Windows runs the process as a dedicated `srt-sandbox` user with a WFP egress fence keyed on its SID** + per-session ACEs). `allowUnixSockets` (e.g. `/var/run/docker.sock`), `enableWeakerNestedSandbox`, MCP-server sandboxing as a first-class use case, and **violation attribution** (`commandId` → `annotateStderrWithSandboxFailures`/`getViolationsForCommand`). Beta preview.
3. *Outer boundary*: devcontainer/Docker/VM. Docs: run `--dangerously-skip-permissions` **only inside container/VM/srt** so hooks, file tools and MCP are inside the boundary — **the CLI refuses that flag as root** (non-root `remoteUser`). The official container ships as a Feature (`ghcr.io/anthropics/devcontainer-features/claude-code:1.0`; pin version via npm + `DISABLE_AUTOUPDATER`) and a reference `.devcontainer` whose **`init-firewall.sh` default-deny iptables allowlist ("supports running Claude Code with `--dangerously-skip-permissions` for unattended work")** needs `NET_ADMIN`/`NET_RAW`. **Mount `~/.claude` as a volume *and* set `CLAUDE_CONFIG_DIR` there** (`~/.claude.json` lives outside; Codespaces clears it on rebuild). Policy: `/etc/claude-code/managed-settings.json` is highest-precedence but **removable by anyone with Dockerfile write access — unbypassable policy needs server-managed settings/MDM**; `permissions.disableBypassPermissionsMode:"disable"` kills the flag. Warning: the container does **not** stop exfiltration of anything inside, including `~/.claude` credentials.

**Context/memory levers.** `/compact <instructions>` and a `# Compact instructions` CLAUDE.md section; hooks that **pre-filter tool output** ("instead of Claude reading a 10,000-line log, a hook greps ERROR"); skills carrying domain knowledge to avoid exploration; MCP tool schemas **deferred by default**; "prefer CLI tools (`gh`, `aws`) over MCP servers because they add no per-tool listing"; `model: haiku` for simple subagents.

**Other primitives.** `/goal` = completion condition judged **after every turn by a small fast model** (`ANTHROPIC_DEFAULT_HAIKU_MODEL`), works as `claude -p "/goal …"`, clears on met / judged-impossible / an error you must fix; complements auto mode (which approves within a turn but never starts one). **Hooks ≈30 events**: three cadences (per-session `SessionStart/End`; per-turn `UserPromptSubmit/Stop/StopFailure`; per-tool `PreToolUse/PermissionRequest/PermissionDenied/PostToolUse/PostToolUseFailure/PostToolBatch`) plus `Setup` (`--init-only`/`--init`/`--maintenance` in `-p` — CI prep), `SubagentStart/Stop`, `TaskCreated/Completed`, `TeammateIdle`, `InstructionsLoaded`, `ConfigChange`, `CwdChanged`, `DirectoryAdded` (+SDK `register_repo_root`), `FileChanged`, `WorktreeCreate/Remove`, `Pre/PostCompact`, `Pre/PostModelSwitch` (can **block** a model switch), `Elicitation`/`ElicitationResult`, `UserPromptExpansion`, `Notification`, `MessageDisplay`; `PermissionDenied` accepts `retry:true` (ignored when the classifier gave no verdict). **OTel**: `CLAUDE_CODE_ENABLE_TELEMETRY=1` + `OTEL_METRICS_EXPORTER=otlp` (metrics 60 s, logs 5 s); **`OTEL_EXPORTER_OTLP_METRICS_TEMPORALITY_PREFERENCE` defaults to `delta`**; content cap `CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH` (60 KB, sized for 64 KB-capping backends); **`OTEL_LOG_RAW_API_BODIES` logs the entire conversation**; **`OTEL_*` is not passed to subprocesses** (Bash/hooks/MCP); managed settings lock the collector by *removing* developer per-signal endpoints/credentials. **Traces (beta)** `CLAUDE_CODE_ENHANCED_TELEMETRY_BETA=1`: `interaction → llm_request | hook | tool{blocked_on_user, execution}` with subagent spans nested; `blocked_on_user` meters **approval wait time** (`decision`, `source`); `tool_use_id` joins spans/events/hook payloads; `llm_request` carries `ttft_ms`, `attempt`, cache read/write tokens, `request_id`, `stop_reason` incl. **`refusal`**, `speed` (`fast|normal`), `query_source`, `agent_id`/`parent_agent_id`/`workflow.run_id`; **Bash/PowerShell children inherit `TRACEPARENT`, and `-p`/SDK sessions read inbound `TRACEPARENT`/`TRACESTATE`** so an orchestrator's trace parents worker spans.
**Cost/usage surface.** Enterprise benchmark: **~$13/dev/active-day, $150–250/dev/month, under $30/day for 90% of users**. Seat allowance = **rolling 5-hour + weekly windows**, shared with chat/Cowork. `/usage`: session cost (list price or admin `modelPricing`; estimates), **attribution by skill/subagent/plugin/MCP server** (MCP share counts only requests consuming its tool result), behavior flags ≥10%, **per-`/loop`-task token rows**; a **prompt-cache line** (≥2.1.251) gives requests, % served from cache, misses (>5% **and** ≥2,000 tokens re-processed), expected rebuilds (compaction/tool-result clearing), warm/cold vs 1 h TTL. Limit taxonomy: session/weekly (seat, model-switching won't help) vs model-family limits; ≥2.1.234 can **wait for the reset and continue the interrupted task automatically** (`autoContinueAtUsageLimit`). Docs' top spend causes: sessions never cleared, Opus left as default. Bedrock/Vertex/Foundry send **no metrics back to Anthropic** — attribution via OTel, a self-hosted Claude apps gateway, or an LLM gateway (LiteLLM: "unaffiliated … not audited"). ## 6. Third-party systems built on Claude Code

- **Continuous Claude** (AnandChowdhary) — closest published twin of DevAgent's loop: bash conductor that per iteration **creates a worktree**, runs `claude -p` (or Codex), pushes, opens a PR via `gh`, waits on **`gh pr checks --watch`**, merges on green / **closes-and-discards on red**, repeats; **`SHARED_TASK_NOTES.md`** as cross-run memory (warns that unprompted the model writes verbose logs that *harm*); `--completion-signal` + `--completion-threshold N` (**N independent passes must agree the project is done**); `--stall-threshold` (no change ⇒ write diagnostics into the notes and pause); `--max-calls-per-hour` + `--error-threshold` (retry through rate-limit reset windows); `-r` reviewer agent validating/fixing the diff **inside the same pass**; `--enable-review-loops` re-invoking on red CI; worktree retention flags + a cron GH-Actions template; **dual-runner fork isolation** — trusted job on a self-hosted runner, untrusted PR code on ephemeral `ubuntu-latest`, patches passed as **artifacts with no secrets in the untrusted job** (caveat: `allow_all_results` lets a fork's own workflow run and exfiltrate). Origin: 0→80% coverage on a ~100k-LOC repo.
- **GitHub Next Continuous AI / `agentics`** — same shape from inside GitHub: research phase + pre-build restore before agentic work; runs are near-idempotent particles — limit-hit-retry or discard-the-PR beats babysitting one run.
- **saulius.io issue-to-merge report** (2026-06-17) — independent synthesis of the first-party mechanics: "GitHub is the system of record; the conversation is ephemeral; what must survive lives in repo files or GitHub"; Explore→Plan→Implement→Commit; **four non-interchangeable review surfaces**; and a myth list — the viral "~100% of Anthropic PRs / 80–90% of reviews" is **unverified**, the defensible claim is "loops, not prompts" / "review the ~80%-complete solution" (descriptive, not a benchmark).
- **OpenClaw** (`docs.openclaw.ai/providers/claude-max-api-proxy`) — a Claude Max subscription exposed as an API endpoint for third-party agents: sitting exactly on Anthropic's "no third-party claude.ai login/rate limits" line and the June metering attempt. (Single source.)
- **OpenHands / Factory / Cline / opencode** — Claude as one provider among many; see `docs/research/2026-09-07-oss-agent-harnesses-scout.md` and PRD §4. That is also DevAgent's stance.

## Cluster synthesis

1. **Anthropic's own pipeline is deliberately *less* autonomous than DevAgent's at the PR boundary** — no auto PR (link only), no rebase/force-push/merge, structurally unable to self-approve, and the review check run **always concludes neutral**. Autonomy is in the work; the last switch is a human or *your* CI parsing the `bughunter-severity` JSON. DevAgent should describe itself as occupying precisely the corner Anthropic chose not to productise.
2. **The reusable contract is: typed stop reason + two independent budgets + a denial ledger + provenance-labelled trigger text** — `result.subtype`, `maxTurns`/`maxBudgetUsd` (subagent-inclusive), `permission_denials[]`, `CLAUDE_CODE_SCRIPT_CAPS`, `<routine-fire-payload>`, `--permission-prompts none`. DevAgent's driver expresses all of these today as exit codes and prose; typing them is the highest-leverage steal.
3. **Trust is allowlists from a trusted source, not prompts**: base-ref restore + `.claude-pr/` quarantine; `filesystem.disabled` from managed/user settings only; **`srt` hard-denying `.git/hooks`, `.mcp.json`, `.claude/{commands,agents}`**; in-repo Dockerfile policy being explicitly bypassable; the CLI refusing bypass as root. Replace DevAgent's PRD-currency heuristic with a trusted-source rule.
4. **Isolation is three composable layers** (permission mode → OS sandbox that *tells the model what it blocked* → container/VM/devcontainer). Violation-with-reason feedback beats DevAgent's kill-on-no-progress watchdog for self-correction.
5. **Context management is a product surface and it is aggressive**: product-set `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` winning over env; `/compact` instructions + a CLAUDE.md preserve-list; `compact_boundary` as a stream event; and the sanctioned reductions are *hooks that pre-filter output*, skills as standing domain context, deferred MCP schemas, CLI-over-MCP. That is the typed answer to Cognition's "share full traces" objection (prior file).
6. **Observability is built for cross-process joins and defaults to `delta` temporality** — the inverse of what a restart-happy ledger assumes. For #291: `blocked_on_user` spans meter approval waits separately, `tool_use_id` joins span↔event↔hook payload, `TRACEPARENT` inheritance lets the driver's trace parent the worker's spans, and `stop_reason: refusal` is a first-class outcome.
7. **The moat question is economic, not model-quality**: paused metering attempt, "estimates are not billing", `/fast` from usage credits, "use an API key for production automation", ToS bar on reselling subscription login — against a $13/dev/day planning anchor. DevAgent's BYO-provider + local-first story is the *compliant* one and should be argued that way in the PRD, while its own Max-subscription loop dependence is its largest external risk.
